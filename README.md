# Chattys 💬

A modern, fast, cross-platform messaging application that lets you connect with friends without needing a phone number. Available across **Web**, **Windows**, and **Android**.

---

## ✨ Features

- **No Phone Number Required:** Sign up and text friends using just a username.
- **Spam-Free Connection Model:** Chatting requires a mutual friend request. No unwanted DMs or spam.
- **Cross-Platform Synchronization:** Seamlessly switch between Web, Windows desktop, and your Android mobile device.
- **Rich Media Support:** Effortlessly send texts and high-quality images in your conversations.

---

## 📦 Downloads & Installation

### 💻 Windows Setup (`.exe`)

1. Go to the latest release page on GitHub under **Releases**.
2. Download the `.exe` installer (e.g., `Chatty-Setup-v1.0.0.exe`).
3. Double-click the downloaded file in your `Downloads` folder to run the setup wizard.
   > **Note:** If Windows displays a *"SmartScreen / Unknown Publisher"* prompt:
   > 1. Click **More info**.
   > 2. Click **Run anyway**.
4. Complete the installation wizard and launch ChatApp.

---

### 🤖 Android Setup (`.apk`)

1. Open the repo's latest release page on your Android device.
2. Download the `.apk` file (e.g., `Chatty-v1.0.0.apk`).
3. Open the downloaded file to begin installation.
   > **Note:** If Android prompts *"Installation from unknown sources is blocked"*:
   > 1. Tap **Settings** in the popup.
   > 2. Enable **Allow from this source** for your browser/file manager.
   > 3. Return to the download screen and tap **Install**.
4. Once installed, launch the app from your home screen or app drawer.

## 🚀 Getting Started

1. **Create an Account:** Register with a unique username+email and password.
2. **Add Friends:** Search for your friends by username and send them a **Friend Request**.
3. **Start Chatting:** Once your request is accepted, your private chat thread will automatically open!
